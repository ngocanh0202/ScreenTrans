# shared/

Dữ liệu dùng chung giữa app Windows (Python) và Android (Kotlin):

- `schemas/` — JSON Schema cho hồ sơ game, bảng thuật ngữ, manifest model (Phase 1).
- `glossary/common.json` — thuật ngữ chung (Phase 1).
- `fixtures/` — bộ test dùng chung; bản Python là chuẩn, bản Kotlin phải pass cùng fixtures.
